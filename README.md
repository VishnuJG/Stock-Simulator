# Stock-Simulator
DBMS project to simulate the stock market

## Overview
This project is designed to provide a user-friendly interface for simulating stock market transactions. Users can log in, view their account details, and perform transactions such as buying and selling shares.

## Features
- User authentication with email and password.
- Display of transaction details and account holdings.
- Ability to buy and sell shares with real-time updates.
- Database integration to store user and transaction data.

## Installation
1. Clone the repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Set up the PostgreSQL database as specified in the documentation.

## Usage
Run the application using `python doc1.py` or `python doc2.py` depending on your preference for the user interface.
