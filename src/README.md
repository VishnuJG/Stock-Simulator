# Stock-Simulator

## Overview
This is a DBMS project to simulate the stock market.

## Structure
- `src/`: Contains all source code files.
- `src/login.py`: Handles user login.
- `src/database.py`: Database connection and queries.
- `src/app.py`: Main application entry point.

## Requirements
- Python 3.x
- psycopg2
- tkinter

## Usage
Run `app.py` to start the application.
